# Getting Started with the Blazor Badge Component

This .NET 10 Blazor WebAssembly sample demonstrates Syncfusion badge styles in a toolbar. The page shows notification badges with values 35, 28, and 98 next to message, user-profile, and favorite icons. The responsive toolbar layout is centered on the page, and the badges use the Syncfusion Bootstrap 5 theme.

## Prerequisites

- .NET 10 SDK
- Access to the Syncfusion Blazor NuGet packages
- A valid Syncfusion license for your use case; license registration is configured in `Program.cs`

## Run the sample

From the project directory, restore and run the app:

```powershell
dotnet restore
dotnet run
```

Open the local URL printed by `dotnet run`. The home page displays the badge toolbar. The Counter and Fetch data routes remain available through the navigation menu.
